Сохранён **15 октября 2026 года**. Прогон выполнялся 14 октября на отдельном
локальном стенде `chicago-readiness`, а не на опубликованном VPS.

Проверялись чтение каталога, страницы и фильтры каталога, категории, филиалы
и `/health/ready`. Системный прокси для локальных запросов был явно отключён.
Лимиты запросов повышались только на изолированном стенде.
Этот прогон не создавал поток заказов и не выполнял реальные платежи.

## Почему остановился

Генератор завершился с `PermissionError: [WinError 5]` при замене временного
файла `soak-8h.tmp` на `soak-8h.json`. Причина отказа Windows в доступе не установлена.
Это ошибка сохранения отчёта; падение приложения в собранных данных не зафиксировано.

Таблица использует последний успешно сохранённый JSON. Также сохранён следующий
временный отчёт: 19 554,3 секунды, 38 777 ответов HTTP 200, ошибок нет.
Он не заменяет основной результат, поскольку финальная запись завершилась ошибкой.
Журнал мониторинга содержит и наблюдения вне активной части этого прогона;
отсутствие рестартов/OOM относится к собранным наблюдениям.

## Вывод и решение владельца

На измеренном участке около 5,5 часа ошибки запросов не обнаружены.
Владелец принял этот промежуточный результат и **15 октября попросил сохранить
отчёт без повторного прогона**. Нагрузочная проверка остановлена; отдельный
сборщик ресурсов после неё также остановлен.

Полный восьмичасовой тест не считается пройденным. Результат не доказывает
устойчивость VPS при реальном потоке заказов и не отменяет отдельный предыдущий
прогон с сетевыми ошибками; его данные сохранены отдельно.

## Исходные данные

Локальный архив исключён из Git: `server/.verification/readiness/saved-soak-20261014/`.
В нём сохранены основной JSON, временный JSON, журнал ресурсов `resources.jsonl`
и сводка `summary.json`. Первоначальные файлы оставлены на месте.
В репозитории хранится этот краткий отчёт без журналов локальной инфраструктуры.

Позднее 15 октября владелец поручил выполнить ещё **2 часа 34 минуты** отдельно.

При запуске зафиксировано начало работы; это ещё не итог второго измерения.

Параметры сохранены: 10 пользователей, пауза 5 секунд, только чтение локального API.
Исправление генератора проверено с настоящей блокировкой файла Windows:
при невозможности замены он сохраняет отдельный JSON и продолжает работу.
Обёртка собирает ресурсы и по завершении автоматически добавляет ниже результат,
включая неполное завершение или ошибки, если они возникнут.
Для выполнения компьютер и Docker должны оставаться включёнными без сна.

Новые данные находятся отдельно: `server/.verification/readiness/soak-followup-20261015/`.
Первый отчёт не перезаписывается. Два участка не считаются непрерывным восьмичасовым тестом.
